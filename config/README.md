# Настройки

Эта папка соответствует структуре шаблона организаторов. Рабочие YAML находятся в [`configs/`](../configs/): не создаём вторую расходящуюся копию.

- `cameras.yaml`: модели камер;
- `clocks.yaml`: частота кадров и сдвиги времени;
- `plan_features.yaml`: геометрия офиса и размеченные области;
- `zones.yaml`: зоны выхода и препятствий;
- `botsort.yaml`: трекер одной камеры.

Секреты и `.env` для локального демо не нужны. Акустические параметры из общего шаблона к задаче компьютерного зрения не применяются.
