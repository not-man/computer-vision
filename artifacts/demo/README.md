# Демо для экспертов

1. В корне проекта выполните `python run.py setup`, затем `python run.py demo`. На Linux/macOS также доступны `make setup` и `make demo`.
2. Откройте http://127.0.0.1:8501 — раздел «Витрина», затем «Треки» и «Как проверяли».
3. Короткий готовый ролик: [`render/full/showcase.mp4`](../../render/full/showcase.mp4). Он показывает результат алгоритма, это не запись управления интерфейсом.
4. Запасной интерактивный отчёт: [`render/full/report.html`](../../render/full/report.html); сохраняйте рядом папку роликов.
5. Перечень: [`results/tracks.csv`](../../results/tracks.csv). Число треков — 64 в исходном коммите `8afe7d0`.

Запись экрана интерфейса пока не приложена. Сценарий и контрольные точки: [`docs/DEMO_SCRIPT.md`](../../docs/DEMO_SCRIPT.md). Исходные видео и кадры содержат людей; режим доступа репозитория определяет команда.
