# Исходный код

Поддерживаемые платформы показа: Windows, Linux, macOS; Python 3.11. Код пакета находится в `src/mct`, приложение — `app/demo.py`, команды — `scripts/`. Полные команды запуска и зависимости: [README проекта](../README.md).

| Компонент | Назначение |
|---|---|
| `mct/perception.py`, `embedder.py` | Детектор, трекер одной камеры, внешность; полный проход на GPU |
| `geometry.py`, `plan.py`, `tracklets.py` | Привязка к плану, фильтрация и разрезы |
| `trinity.py` | Ассоциация между камерами, разрывы и возвраты |
| `render.py`, `report.py`, `showcase.py` | Мозаика, отчёт и короткий ролик |
| `summary.py`, `charts.py` | Общие данные интерфейса и отчёта |

Готовые веса детектора и OSNet используются как компоненты. Правила межкамерного связывания написаны командой. Разметка для оценки не должна использоваться для назначения итоговых ID: подробнее `docs/TEST_RESULTS.md`.
