# Независимая точечная проверка ID v1

`holdout_points_v1.csv` размечен по исходным кадрам без нарисованных рамок и итоговых номеров алгоритма. Общие секунды от 17:00:00 переводятся в исходный номер кадра по `configs/clocks.yaml`; координаты даны на уменьшенном до 900×675 изображении. Исходные видео — `data/camera_new_*.mkv`. Для сравнения выбирается ближайший из кадров детектора при 10 кадрах/с (не дальше 0,05 с). Окна: 17:48:38–48 и 17:56:23–33, вне размеченной толпы 17:45:25–47. Одежда служит временным именем человека, не распознаванием личности.

В выборку вошли только точки, где одежда, движение и переход между соседними камерами позволяют уверенно продолжить человека. Далёкие фигуры и перекрытия без ясной принадлежности не подписаны. Это **неполная выборка для проверки связи ID и пропусков в выбранных точках**, не эталон всех людей, детекций или всей записи; по ней нельзя заявлять общий IDF1/MOTA/HOTA. Порогов алгоритма по этим точкам не подбирать. При сравнении новых правил применять их как финальную проверку после выбора по другим данным.
