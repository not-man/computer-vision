# Разметка только для оценки

`fragment_truth.py` содержит метки одежды на фрагменте 17:45:25–17:45:47 и 28 контрольных пар. Они использовались при настройке: это не независимый тест и не разметка всей записи.

Алгоритм связывания `src/mct/trinity.py` и построение треклетов не импортируют этот модуль. В `scripts/link_tracks.py` сначала вычисляется `result = link_tracklets(...)`, затем отдельная функция измеряет `quality` для уже полученного результата. Метки не назначают номера и не меняют связи. Остальные потребители — скрипты оценки, сравнения экспериментов и тесты.

Установка проекта включает пакет `evaluation`, чтобы команды оценки были одинаковы на Windows и Linux. Перенос модуля не меняет разметку или правила алгоритма.
