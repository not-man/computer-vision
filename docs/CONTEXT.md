## 1. Задача

Хакатон NtechLab «Nuclear IT Hack», команда **ТОКЕНЫ ЗАКОНЧИЛИСЬ**. Пользователь хочет победить. Задача: сквозной трекинг людей по пяти камерам офиса на записи длиной 20 минут. ТЗ и презентация организаторов лежат в `docs/brief/`.

Правила подсчёта:
- один номер, пока человека видит хотя бы одна камера;
- трек через несколько камер считается один раз;
- треков может быть больше, чем людей;
- **ответ организаторов на чекпоинте: длительное отсутствие значит больше одной минуты, если человека нет ни в одном кадре.** Дольше минуты трек закрыт, вернувшийся получает новый номер.

Критерии (слайд 9): ID при переходе, завершение трека, подсчёт, повторяемость, понятность демонстрации.

Что сдать: работающий прототип и код; короткая инструкция и зависимости; алгоритм в интерфейсе на предоставленном видео; число и перечень уникальных треков (ID, начало, конец, камеры); описание: алгоритм, готовые компоненты, ограничения, улучшения. ## 5. Как устроено решение

Подробно: `docs/SOLUTION.md`, `docs/ARCHITECTURE.md`, `docs/DESIGN.md` (раздел 0 важнее остальных).

- **Данные.** 5 камер, по 20 минут, 2592×1944, `cam_4` HEVC 20 кадр/с, остальные H.264 25 кадр/с, всего 231 МБ, очень низкий битрейт. Метки времени в файлах сломаны: время только из номера кадра и `configs/clocks.yaml`, сдвиги камер до 0.8 с измерены по людям.
- **Восприятие, GPU, `src/mct/perception.py`.** YOLO11m-seg, вход 960, порог 0.1, BoT-SORT (`configs/botsort.yaml`), 10 кадров в секунду, рамки и маски в размере 1296×972. OSNet-AIN `osnet_ain_x1_0_msmt17` через BoxMOT. Результат: `artifacts/perception/*.parquet`, `*_emb.npz` (1 снимок в секунду, для разрезов), `*_emb_dense.npz` (каждое третье наблюдение, для вектора куска).
- **Положение и фильтр, CPU, `geometry.py`, `plan.py`, `tracklets.py`.** Модели камер `configs/cameras.yaml`, план 29 пикс/м, стопа по маске или от головы и роста, у каждой точки своя ошибка. `relocate_hidden_feet`: дальше 15 м и рост на 0.2 м ниже своего, положение по макушке, свой рост ограничен 1.65–2 м. Фильтр ложных и разрезы: `find_identity_jumps`, `find_tail_swaps`.
- **Склейка, `trinity.py`.** Порядок уровней: `sustained`, `brief`, `contacts`, `gaps`, `returns`, `finish`. Признаки G (расстояние), T (время), R (сходство после вычитания среднего вектора камеры). Запреты: `_compute_conflict`. Причина закрытия: `ZoneMap.closing_kind`.
- **Вывод.** `scripts/link_tracks.py`, `render_mosaic.py`, `draw_gallery.py`, `check_robustness.py`, `make_showcase.py`, `make_report.py`, `demo_check.py`. Интерфейс `app/demo.py`. Общие части: `src/mct/charts.py`, `summary.py`, `report.py`, `showcase.py`. Известные ошибки для показа: `KNOWN_ERRORS` в `summary.py`, их проверяет `make check`.
- **Оценка, `evaluation/fragment_truth.py`.** Разметка толпы и 28 пар. Алгоритм её не импортирует, но на этих примерах правила настраивались.
