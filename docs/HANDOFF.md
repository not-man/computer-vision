## Версия для сдачи

Ветка `mct-pipeline`: базовое восприятие, 61 сквозной трек (подробности в [CONTEXT.md](CONTEXT.md)), проверенные исправления запуска на Windows и контрольных сумм. Продолжать поддерживать Windows и Linux/macOS одновременно. Сохранить переносимый `run.py`, существующий Makefile и нормализацию переводов строк при хешировании. Работа на Linux не является основанием удалять Windows-поддержку.

- Windows: `python run.py setup`, `python run.py check`, `python run.py test`, `python run.py demo`.
- Linux/macOS: прежние `make setup`, `make check`, `make test`, `make demo`; переносимый запускатель также доступен.
- Пересчёт склейки на Windows для прежней версии с 75 треками дал тот же CSV после нормализации переводов строк; итоговую версию с 61 треком на Windows ещё не проверяли. JSON отличался только полями хеша настроек; хеш YAML теперь также нормализуется.
- Тяжёлую детекцию запускать только в Colab на GPU. Новый полный GPU-проход для сдачи не требуется.
- Пользователь решил пока не добавлять LICENSE. Значение `gap_veto=0.15` сохранено.
- `main` не изменять без отдельного указания. Репозиторий закрытый: в нём записи с людьми.

## Эксперименты

Ветка `mct-experiments-codex` сохраняет ROI-детекцию, частый ReID, Colab-пилоты и материалы проверки. Это не принятые улучшения итогового распознавания. Не переносить их в сдаваемую версию без измеренного выигрыша и проверки регрессий.

Пилот v1 выявил дубли головы/тела. Дедупликация v2 прошла программные тесты, но повторный GPU-пилот ещё не проверен. Улучшение ID и полноты распознавания там не доказано. Частые снимки в `mct-pipeline` посчитаны отдельно и проверены измерениями, см. CONTEXT.md.

Приоритет перед сдачей: репетиция показа, комплект результатов и зависимостей, офлайн-отчёт, честное описание известных ошибок. Число тестов не является метрикой точности трекинга; 61 — результат алгоритма, не эталонная численность людей.
