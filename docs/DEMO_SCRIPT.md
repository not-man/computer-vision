# Показ за пять минут

Этот сценарий относится к локальному показу с 60 треками на `http://127.0.0.1:8502`. На GitHub пока остаётся согласованная версия с 61 треком; её числа приведены в [TEST_RESULTS.md](TEST_RESULTS.md).

## Подготовка

До выхода: `python run.py check`; открыть приложение и запасной отчёт; проверить звук не требуется. Вывести интерфейс на экран защиты и отключить уведомления самостоятельно. При записи экрана записывать только окно демо, чтобы не захватить посторонние данные.

## Сценарий защиты

| Время | Экран и действие | Основная мысль |
|---|---|---|
| 0:00–0:30 | Витрина: 60 треков, 5 камер | Считаем траектории наблюдения, а не распознаём личность |
| 0:30–1:30 | Запустить короткий ролик | Силуэты и единый номер при переходах; путь на плане |
| 1:30–2:20 | «Треки»: выбрать длинный трек с несколькими камерами, например #41 | Видео с жёлтой рамкой выбранного трека на всех камерах, снимки, время, основания связей |
| 2:20–3:00 | Объяснить схему алгоритма | Готовые детектор и ReID; собственные синхронизация, геометрия, правила связей |
| 3:00–3:40 | «Как проверяли» | Толпа: 1551 из 1639 размеченных рамок на своём треке (0.946), чистота 0.955; пары 27/28, по ним настраивали правила. Таблица «Проверки по всей записи»: 309 связей, в том числе 2 новые; закрытий верно 58 из 60; независимые точки 41 из 42. Просмотр по снимкам предварительный, без независимой повторной проверки. Ниже таблица прежних опытов |
| 3:40–4:20 | Известные ошибки #32 и #21 | Не скрываем перескок и двоих в одной маске; нет полной оценки всей записи |

## Запись экрана на 2–3 минуты

Записать витрину и ролик; перейти в «Треки», выбрать трек, показать камеры и снимки; открыть «Как проверяли» и ограничения. Сохранить `artifacts/demo/interface_walkthrough.mp4`. После записи просмотреть файл от начала до конца. До появления файла не утверждать, что запись экрана готова.

## Ответы на вопросы

- **Почему 60, а не число людей?** Один человек может иметь несколько треков; ошибки фрагментации и слияния остаются.
- **Почему связываете после исчезновения?** Организаторы определили длительное отсутствие как больше минуты, поэтому вернувшегося быстрее минуты считаем тем же человеком, если он уверенно похож. Это решение команды. Такие связи отмечены в досье, все 30 просмотрены. Запасной перечень без них: 91 трек, `results/tracks_without_returns.csv`.
- **Это IDF1?** Нет. Частичное соответствие и чистота на 22 секундах плюс контрольные пары. Полного независимого эталона нет.
- **Что написала команда?** Межкамерная логика, синхронизация по кадрам, привязка к плану, фильтрация, объяснение связей, интерфейс и отчёт.
- **Что сделаете дальше?** Независимая разметка, проверка переходов и завершений; затем улучшения дальних детекций и сложных перекрытий.
