- Окружение: `uv sync --extra cpu` на машине без GPU.

## Перенос на другой ноутбук
```bash
git clone -b mct-pipeline https://github.com/not-man/computer-vision.git
cd computer-vision
make setup
make demo
```
Нужны вход в GitHub, `uv` и `make`; `make` и пути `.venv/bin` рассчитаны на Linux и macOS. Память Claude Code на другой ноутбук не переносится: всё нужное записано здесь.

## Как пересчитать
```bash
make all      # всё после детекции: треки, мозаика, снимки, проверка устойчивости, витрина, отчёт
make check    # проверка файлов перед показом
make demo     # проверка и интерфейс
make test
```
Склейка занимает секунды, рендер меньше 5 минут, галерея около 2–3 минут. Детекцию и ReID запускать только в Colab: `colab/run_perception.ipynb`, архив кода собирает `scripts/make_colab_bundle.py`.
